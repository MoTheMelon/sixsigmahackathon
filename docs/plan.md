## Tasks (CONTRACT order; H-08 repo already exists, so H-06 can deploy right after H-04)

1. **H-01 SPEC.md** (`SPEC.md`). Test: `grep -c "FILL IN[.,]" SPEC.md` prints 0. Done 2026-10-16.
2. **H-02 data** (`data/`), ~1 h. `telemetry.csv`, `coupons.csv`, `edge_case.csv` + `data/README.md`
   codebook, generated by a seeded script `data/make_data.R`. Test: B-27 O2 ramp from layer 120 is
   present; builds 1-20 are flagged `baseline`; the edge file has a constant build and a 1-coupon build.
3. **H-03 statistics** (`app/qc.R`, `tests/`), ~3 h. One plain function each:
   - `capability(x, build, lsl=NA, usl=NA)`: sigma_w = s-bar / c4(n), c4(n) = sqrt(2/(n-1)) G(n/2)/G((n-1)/2);
     sigma_o = sd(x); Cpk = min((mean-LSL), (USL-mean)) / (3 sigma_w) over the limits given;
     Ppk same with sigma_o; Cp = Pp = (USL-LSL)/(6 sigma) only when both limits exist, else NA + "one-sided spec".
   - `xbar_s_limits(x, build)`: CL = mean of build means; X-bar limits CL +/- A3 s-bar, A3 = 3/(c4 sqrt(n));
     S limits B3 s-bar, B4 s-bar, B3/B4 = 1 -/+ 3 sqrt(1-c4^2)/c4 (B3 floored at 0).
   - `nelson_rules(x, cl, sigma)`: rule 1 |x-CL| > 3 sigma; rule 2 nine in a row one side; rule 3 six in a row
     steadily up or down; rule 4 fourteen in a row alternating. Returns one row per point, a flag per rule.
   - `ewma_chart(x, mu0, sigma, lambda=0.2, L=3)`: z_i = lambda x_i + (1-lambda) z_(i-1), z_0 = mu0;
     limits mu0 +/- L sigma sqrt(lambda/(2-lambda) (1-(1-lambda)^(2i))); flag z outside.
   - `normality_check(x)`: Shapiro-Wilk p-value (needs 3-5000 points).
   Known-answer tests (SPEC 4): Cpk 1.772, Ppk 1.633, X-bar 1090.46 / 1129.54, B4 s-bar 25.68,
   EWMA z3 110 > UCL3 108.59, UCL1 106.00; planted rule-2 run flags point 19 only; cross-check vs `qcc`.
   Degenerate tests: constant data gives NA + "zero variation: capability undefined"; 1 coupon per build errors
   "need at least 2 coupons per build"; EWMA with sigma = 0 errors; NA values dropped with a warning.
4. **H-04 Shiny app** (`app/`), ~3 h. Copy `demos/shinyapp/`, bslib pages 1-2 calling only `qc.R`.

## Decisions (2026-10-16)
- Scope: capability + SPC (X-bar/S, EWMA, Nelson 1-4). Lasso/RF, PDF report, live feed out of scope.
- One-sided specs: report Cpk and Ppk; Cp/Pp shown as "n/a: one-sided spec". No invented USL.
- Control limits from a Phase I baseline (first 20 builds), Nelson rules 1-4 only.
- Capability banner reads "NOT INTERPRETABLE" when any Nelson rule fires on the X-bar/S chart.
- Abort rule (H-09): EWMA L = 3 kept for the chart; ABORT only after 5 consecutive out layers (`abort_index`). Badge RED also when fleet Cpk < 1.33.
- Stack: R Shiny + bslib + plotly + DT; statistics in base R; `qcc` only as a test cross-check.

## Risks
1. **Porosity is skewed (bounded at 0)**, so the normal-theory Cpk is off. We show the Shapiro-Wilk warning
   and say so in the README; no transform in the core.
2. **R packages are not installed and Connect needs exact versions.** Install early, use `renv`-free
   `rsconnect::writeManifest()` from `manifestme.R`, deploy right after H-04.
3. **Scope creep from the original 3-page concept.** Page 3 stays a stretch task until H-03 to H-06 pass.
